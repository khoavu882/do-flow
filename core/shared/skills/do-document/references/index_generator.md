# Project Index & Architecture Reference

Methodology for creating whole-repository knowledge indexes:

## Index Sections
1. **System Overview**: High-level purpose, tech stack, and primary runtime architecture.
2. **Directory Map**: Key directories, responsibilities, and boundary layers.
3. **Core Workflows**: End-to-end trace of primary data flows and API request paths.
4. **Key Invariants**: Non-obvious architectural constraints and governance rules.
