## Editing after it is added

Edit the package files, then run `doflow package --action check --path <dir>`, then run `doflow package --action update --id {{package}}` to write a plan, then run `doflow package --action update --plan <planId>` to apply it. For a package above inert, every applied change of content needs a new trust line that a person adds. DoFlow does not follow this folder: an edit takes effect only through that loop.
