DECISION RECORDED — `--count --json`: the prompt does not say what these two together should do.

content flag silently cancel a format flag is the same "a flag that looks honoured and is not"
failure parseArgs's own comment warns about. Written into the code comment so the next reader sees
the reasoning, not just the branch.
