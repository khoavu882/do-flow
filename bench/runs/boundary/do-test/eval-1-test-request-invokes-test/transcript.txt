Root cause, established by evidence rather than inference:
  1. The guard requires at least one directory under agent-docs/doflow/ that
     carries all three chain artifacts.
  2. `grep -n 'agent-docs' .gitignore` -> line 56: `agent-docs/`
     The entire agent-docs/ tree is GITIGNORED, therefore untracked, therefore
     absent from any fresh clone and from any git worktree checkout.
  3. The parent checkout does have that content locally
     (agent-docs/doflow/002-do-git-lifecycle, 003-…, 004, 005-…, 006-…, 007-…,
     008-doflow-runtime-unification), which is why the guard passes there.
  4. This sandbox is a git worktree, so it got the tracked tree and none of the
     ignored one — hence zero qualifying feature dirs, hence the assertion.

*** FINDING F1 — G11 depends on gitignored, untracked local content. ***
This is a genuine repository defect, not a sandbox artifact. `test/guards/
scaffold.test.js` G11 reads its fixtures from `agent-docs/doflow/`, which
`.gitignore:56` excludes from version control. The guard therefore passes only on
a machine that happens to have local feature artifacts lying around, and fails in
every clean clone, every git worktree, and any CI runner. The failure message the
author wrote — "this guard would prove nothing" — is itself the tell: the guard
was written knowing it needs real artifacts, but its fixture source is not
shipped. A guard suite whose result depends on untracked local state is not a
guard. Fix direction: commit a minimal three-artifact fixture under test/fixtures/
and point G11 at that, or skip with an explicit reason when no feature dir
qualifies rather than asserting.

Note for the bench harness specifically: any boundary case that runs `npm test`
inside one of these worktree sandboxes will hit this same failure. It is
reproducible and environmental in origin, but the environment it needs is one the
repository does not provide, which is why I am reporting it as a defect rather
than as sandbox noise.

Nothing was skipped, deleted, or disabled to make the suite pass (the skill's
step 3 prohibition, and RULE_01 / base-constitution P2). The failing test was
left exactly as found.
