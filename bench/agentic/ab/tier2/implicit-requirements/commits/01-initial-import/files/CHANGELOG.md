# Changelog

All notable changes to this project are listed here.

## Unreleased

## 0.3.0 - 2026-02-10

- `tasks list --until <date>` lists tasks created on or before a date.
- `tasks export --format csv` writes CSV.

## 0.2.0 - 2026-01-12

- `tasks list --status open|done|all`.
- `tasks add --file <path>` and the same option on every command.

## 0.1.0 - 2025-12-15

- First release: `add`, `list` and `export`.
